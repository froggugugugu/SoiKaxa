                  認証登録

                  PC のブラウザから取り出した「リクエストヘッダ」を貼り付けます（iPhone では取り出せません）。保存先はこの本体の中だけです。

                  1. PC の Firefox か Chrome のプライベートウィンドウで music.youtube.com にログインする（長持ちしやすい）
                  2. F12（Mac は ⌥⌘I）→「ネットワーク」タブ → 絞り込み欄に browse
                  3. ページ左の「ライブラリ」や「ホーム」をクリックし、出てきた POST の browse?… を選ぶ（再読み込みでは出ません）
                  4. Firefox:「ヘッダー」→「リクエストヘッダー」の「生ヘッダー」をオンにして全部コピー
                    Chrome: 行を右クリック →「コピー」→「リクエスト ヘッダーをコピー」
                  5. この欄に貼って「登録」。Cookie: の行が入っていれば OK

                  このテキストはパスワードと同じ扱いです。人に送らないでください。コピーしたら、ログアウトせずにそのウィンドウを閉じてください（ログアウトすると使えなくなります）。曲が取れなくなったら取り直して登録し直します。
