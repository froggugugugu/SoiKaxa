# 設計判断の記録（ADR 形式・要約）

日付はすべて 2026-10-31〜11-01 の検討。

| # | 判断 | 理由 | 却下した案 |
| --- | --- | --- | --- |
| D-01 | 本体は Linux ボード（Raspberry Pi） | YouTube Music の認証・URL 解決（yt-dlp）・AAC/Opus デコード・A2DP Source を ESP32 単体で維持できない | ESP32 単体 / ESP32-S3 + 外付け BT モジュール |
| D-02 | 単体完結。中継サーバー・外部サービスを使わない | 「端末だけ持っていけば動く」が最優先要件。Tailscale 等は便利だが依存を嫌う | ESP32 + 自宅 Pi 中継 / Tailscale Funnel |
| D-03 | 本体は手元の Pi 4B。Zero 2 W は任意のスリム版 | Zero 2 W は 2026 年現在供給不安定（公式代理店品切れ、Amazon 転売 2 万円）。ソフトは共通で後から移植可 | Zero 2 W を待つ / Orange Pi Zero 2W 等（技適なし） |
| D-04 | 再生は mpv + yt-dlp を端末内で直接。トランスコードなし | mpv が yt-dlp と連携して AAC/Opus をそのまま再生。ffmpeg 中継は不要 | Pi 側で MP3 にトランスコードして配信 |
| D-05 | 操作はスマホ。端末 AP + キャプティブポータルで QR 一発 | ゲストがアプリ・アカウント不要で参加できる。インターネットなしでも会場内で完結 | 会場 Wi-Fi の資格情報を QR で配る（クライアント隔離で届かないことがある） |
| D-06 | 画面は 3.5 インチ SPI LCD HAT（480×320、抵抗膜タッチ）。表示主体 | 配線ゼロ、約 2,000 円。操作をスマホに寄せるため高価なタッチ UX は不要 | 1.3/2.8 インチ SPI（小さい、配線要） / DSI・DPI 静電容量（5,000〜9,000 円） |
| D-07 | 物理ボタン廃止、タッチでタップ=再生/停止・長押し=次曲のみ | HAT が GPIO を覆う。最低限の即応操作はタッチで足りる | タクトスイッチ 2〜4 個 |
| D-08 | コアとソースアダプタをリポジトリごと分離 | オープンソース化時、YouTube 依存部分を切り離せる。ローカル MP3・ネットラジオ・Spotify に広げられる | 単一リポジトリ |
| D-09 | アダプタ I/F は 4 関数（list_playlists / list_tracks / search / resolve） | コアを最小に保つ。ローカル MP3 アダプタは数十行で書ける | 豊富な I/F |
| D-10 | プロジェクト名 **SoiKaxa**（バスク語 Soinua Kaxa＝音の箱）。識別子は `soikaxa`。YouTube/yt を名前・SSID に含めない | 商標と誤認の回避。意匠設計の検討で命名。GitHub/一般検索で衝突なし（2026-11-21 時点） | ytbox（仮称）/ Kerobox（初期案） |
| D-11 | Amazon Music は対象外 | 第三者向け再生 API がなく Widevine DRM。DRM 回避はしない方針 | — |
| D-12 | Wi-Fi 登録は 3 経路（一覧/手入力ステルス/写真） | 会場 Wi-Fi はステルスや長いパスワードが多い。iOS Live Text と撮影→jsQR 解読で入力負荷を下げる | 一覧のみ |
| D-13 | 起動高速化を最初から組み込む | 「電源をつなぐだけ」の体験に直結。目標 20 秒 | 後回し |
| D-14 | スリム版（Pi Zero 2 W）の名称は **SoiKaxa Txiki**（txiki＝小さい）、識別子 `soikaxa-txiki`。ソフト共通、機種名を設定で切替 | 4B 版と区別し、小型化の目標を名前で示す | 全部同名 / Tadbox（初期案） |
| D-15 | 音源は YouTube Music のまま。Spotify は見送り | YouTube Music ファミリー契約を活用（Spotify は家族分の二重課金）。Spotify は Connect/Jam で同コンセプトの既製品・OSS が揃い独自性が消える。SoiKaxa の存在理由は YouTube Music に端末プロトコルもゲストキューもないこと | Spotify 主軸 / yt-dlp を ESP32・Zero W 向けにフォーク（JS 実行環境必須で不可） |
| D-16 | UI はサイバー系（暗背景・シアン/マゼンタ・等幅）。再生中はジャケット写真入りレコードを回転表示 | 見た目の満足度。SPI でも円盤だけ動かせば成立する（事前生成フレームを部分書き込み） | 全画面アニメーション（SPI では不可） |
